# 02 二极管

> 对应计划 W2。第一种半导体器件：一个 PN 结，单向导电。

## 1. PN 结与单向导电性

P 型半导体（多子空穴，带正电倾向）与 N 型（多子电子）结合：

- 交界处扩散形成**耗尽层**（内建电场）
- **正偏**：P 接 +、N 接 −，外电场抵消内电场，耗尽层变窄 → 多数载流子顺利通过，**导通**
- **反偏**：P 接 −、N 接 +，耗尽层变宽，只有极小的反向漏电流 → **截止**

这就是二极管（阳极 A = P，阴极 K = N）单向导电的原理。

## 2. 伏安特性与恒压降模型

实际伏安特性是指数曲线（肖克莱方程，了解）：

$$I_D = I_S\left(e^{V_D/V_T}-1\right), \qquad V_T\approx 26\text{mV（室温）}$$

工程上用**恒压降模型**：导通后管压降近似固定：

| 材料/类型 | 导通压降 $V_D$（典型） |
|-----------|------------------------|
| 硅开关/整流管（1N4148、1N4007） | 0.6–0.7V |
| 肖特基管（SS34、1N5819） | 0.2–0.4V |
| 发光二极管 LED（普通红） | 1.8–2.2V |
| LED（蓝/白） | 2.8–3.3V |

电流随电压指数上升，所以二极管**不能直接并在电压源上**，必须串联限流电阻，否则电流无限增大烧毁。

### 限流电阻计算（以 LED 为例）

$$R = \frac{V_{supply} - V_F}{I_F}$$

**例**：5V 驱动红色 LED，$V_F=2$V，取 $I_F=10$mA：

$$R = \frac{5-2}{0.01} = 300\Omega \;(\text{取标称值 }330\Omega)$$

> 🔌 万用表二极管档：红笔接阳极、黑笔接阴极显示约 0.5–0.7（硅管），反接显示 OL（溢出）。据此可判断管脚与好坏。

## 3. 半波整流

![半波整流电路](../images/half-wave-rectifier.svg)

利用二极管单向导电，把交流变成脉动直流：

- **正半周**（上端为正）：D 正偏导通，电流流过负载 $R_L$，$V_{out}\approx V_{ac}-0.7$
- **负半周**：D 反偏截止，回路无电流，$V_{out}=0$

结果：负载上只有半个周期的馒头波——**半波整流**。

关键参数：
- **峰值反向电压 PIV**：截止时二极管承受的最大反向电压 ≈ $V_{ac(peak)}$，选管时反向耐压必须大于它并留裕量
- 输出平均值（不加滤波）：$V_{out(avg)} = \dfrac{V_{peak}}{\pi}\approx 0.318V_{peak}$

加一个并在负载两端的大电解电容（注意极性）可把馒头波填成较平滑直流：电容在波峰充电、波谷向负载放电，放电时间常数 $R_LC$ 越大纹波越小。这是线性电源「变压→整流→滤波→稳压」的第三步。

> 全波/桥式整流用 4 只二极管，两个半周都利用，纹波频率翻倍（100Hz），更易滤波，是实际产品主流。

## 4. 二极管的其它典型用法

- **续流**：反向并在继电器、电机线圈两端。开关断开时电感电流经二极管续流，钳位电压尖峰（二极管方向：平时反偏不导通，断电瞬间正偏）
- **限幅/钳位**：把信号顶部削在某电平，保护后级输入
- **防反接**：串联在电源入口，接反时截止（有 0.7V 压降损耗；大电流场合改用 MOS 防反接）

## 5. 稳压二极管（齐纳二极管）

普通硅二极管反偏到一定电压会击穿。稳压管工作在**反向击穿区**，只要电流限定在允许范围，击穿是可逆的，且两端电压几乎不变。

![稳压管电路](../images/zener-regulator.svg)

**并联稳压电路**：输入经限流电阻 $R_s$，稳压管 $D_z$ 与负载 $R_L$ 并联。

工作原理：
- 输入升高/负载变轻 → 多余的电压差降在 $R_s$ 上，$D_z$ 电流自动增大，把节点电压钳在 $V_z$
- 输入降低 → $D_z$ 电流减小，电压仍钳在 $V_z$（前提：电流不低于稳压管最小维持电流，一般几 mA）

### $R_s$ 计算

设输入范围 $V_{in}$、要求输出 $V_z$、负载电流范围 $0\sim I_{L(max)}$：

$$R_s = \frac{V_{in} - V_z}{I_z + I_L}$$

要同时校验两个极端，使稳压管电流落在 $I_{z(min)}$ 与 $I_{z(max)}=\dfrac{P_z}{V_z}$ 之间。功率：$P_z=V_z I_z$ 不得超过额定值（常见 0.5W、1W）。

**例**：输入 9V，要得到稳定 5.1V，负载电流 0–10mA，取稳压管电流约 5mA：

$$R_s=\frac{9-5.1}{(5+10)\text{mA}}=260\Omega\;(\text{取 }270\Omega)$$

输入最高、负载为 0 时稳压管电流最大：$I_{z(max)}=(9-5.1)/270=14.4$mA，$P=5.1\times14.4\text{m}=73$mW，0.5W 的 1N4733A 足够。

> ⚠️ 稳压管稳压只适合小电流、对精度要求不高的场合（基准、偏置）。负载电流稍大、效率要求高时用 LDO；注意稳压管输出有噪声、温漂，做精密基准常用专用基准芯片（TL431、REF30xx）。
