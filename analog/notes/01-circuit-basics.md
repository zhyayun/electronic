# 01 电路基础

> 对应计划 W1。模电一切分析的地基：两个定律、两个模型、两个储能元件。

## 1. 电压、电流与功率

- **电流 $I$**：电荷的流动，单位 A（安培）。规定正电荷流动方向为电流正方向（与电子实际运动方向相反）。
- **电压 $V$（电位差）**：单位电荷从一点移到另一点释放/吸收的能量，单位 V。说电压必须指明**哪两点之间**。
- **关联参考方向**：电流从元件电压的「+」端流入、「−」端流出。

功率（关联方向下）：

$$P = VI$$

- $P > 0$：元件**吸收**功率（电阻、充电的电池）
- $P < 0$：元件**发出**功率（电源）

电阻消耗的功率：

$$P = VI = I^2R = \frac{V^2}{R}$$

> 🔌 实测意识：选电阻/器件时功率必须降额。$1/4$W 电阻在 $P > 0.25$W 时会烫手甚至烧黑，设计按实际功耗的 1.5–2 倍选额定功率。

## 2. 两个基尔霍夫定律

### KCL（节点电流定律）

任一节点，流入电流之和 = 流出电流之和：

$$\sum I_{in} = \sum I_{out}$$

本质：电荷不能在节点堆积。

### KVL（回路电压定律）

沿任一闭合回路走一圈，电压升之和 = 电压降之和：

$$\sum V = 0$$

本质：能量守恒。绕圈时遇到的每个元件，电位降取正、升取负，一圈回到原点电位不变。

> 分析套路：先标电流方向（猜错了只会得到负号），再对节点列 KCL、对回路列 KVL。

## 3. 电阻串并联与分压分流

串联：$R = R_1 + R_2 + \cdots$，流过同一电流。

并联：$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots$，即两电阻 $R = \dfrac{R_1R_2}{R_1+R_2}$，两端同一电压。

### 分压公式

![分压电路](../images/voltage-divider.svg)

$$I = \frac{V_{in}}{R_1+R_2}, \qquad V_{out} = IR_2 = V_{in}\frac{R_2}{R_1+R_2}$$

**例**：$V_{in}=5\text{V}$，$R_1=R_2=10\text{k}\Omega$ → $V_{out}=2.5\text{V}$。

> ⚠️ 分压只在**输出不取电流**时成立。一旦 Vout 接了负载 $R_L$，$R_2$ 实际与 $R_L$ 并联，电压就变了。这就是为什么不能用两个电阻直接给 MCU 供电——必须用运放跟随或 LDO。

### 分流公式（两电阻并联）

$$I_1 = I_{total}\frac{R_2}{R_1+R_2}$$

电阻越大，分到的电流越小（注意和分压相反）。

## 4. 戴维南等效

任何一个线性二端网络，从端口看进去都可以等效为：

$$V_{th} = \text{端口开路电压}, \qquad R_{th} = \text{独立源置零后端口看进去的电阻}$$

用途：分压电路接负载后，直接把分压网络看成 $V_{th}$ 串 $R_{th}$，再接 $R_L$ 算一次分压即可，不必重列方程。

**例**：上面 5V + 两个 10kΩ 分压，$V_{th}=2.5$V，$R_{th}=10\text{k}//10\text{k}=5\text{k}\Omega$。若再接 $R_L=5\text{k}\Omega$，实际输出 $=2.5\times\dfrac{5}{5+5}=1.25$V——掉了一半，直观说明分压带载能力差。

## 5. 电容

$$i_C = C\frac{dv_C}{dt}$$

- 直流稳态下 $\frac{dv}{dt}=0$ → 电流为 0：**电容隔直流**
- 电压不能突变（突变需无穷大电流）
- 储能：$E_C = \frac{1}{2}CV^2$

实际电容不是理想的：有 **ESR**（等效串联电阻）、ESL，大容量电解还有漏电流。高频滤波要用 ESR 低的陶瓷电容。

## 6. 电感

$$v_L = L\frac{di_L}{dt}$$

- 直流稳态下电流不变 → 两端电压为 0：**电感对直流相当于短路（只留导线电阻）**
- 电流不能突变（突变产生无穷大电压尖峰）
- 储能：$E_L = \frac{1}{2}LI^2$

> ⚠️ 带电感的回路突然断开（如继电器线圈断电），$\frac{di}{dt}$ 极大，会产生几百上千伏尖峰打穿开关器件。必须并联**续流二极管**给电感电流一条释放路径。这是后面 BJT/MOS 驱动继电器、电机的必考点。

## 7. RC 暂态过程（一阶电路）

![RC 充放电电路](../images/rc-charge.svg)

阶跃输入 $V_{in}$ 通过 R 给 C 充电，电容电压：

$$v_C(t) = V_{in}\left(1 - e^{-t/\tau}\right), \qquad \tau = RC$$

放电（输入短路）：

$$v_C(t) = V_0 e^{-t/\tau}$$

| 时刻 | 充电到 |
|------|--------|
| $t=\tau$ | 63.2% |
| $t=3\tau$ | 95.0% |
| $t=5\tau$ | 99.3%（工程上认为充满） |

**例**：$R=10\text{k}\Omega$，$C=100\mu\text{F}$ → $\tau=1\text{s}$，约 5 秒充满。

> 🔌 实验：信号发生器给 RC 输入方波，示波器双通道看 $V_{in}$ 与 $v_C$。改变 R 或 C，指数曲线的快慢随之改变。这是理解后面 PWM 输出加 RC 变直流、运放滤波的起点。
