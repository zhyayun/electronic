# 四个月硬件学习计划

> 周期：2026-11-05 ~ 2027-03-03（共 17 周）
> 节奏：**每天 3 小时，约 21h/周，总计约 350h**。
> 主线：**模电/数电并行打基础 → MCU 电控 → 电源 → 自制 PCB 综合项目**。

## 总目标

四个月后独立完成一个 **自制 PCB 的 MCU 数控可调 Buck 电源**：自己算参数、LTspice 仿真、KiCad 画板打样、焊接调试、写闭环固件，用示波器/电子负载完成指标测试并写复盘。

参考指标（W15 可按实际器件调整）：输入 12V，输出 3–10V / 0–2A，步进 0.1V，OLED 显示设定值/实测电压电流，带过流保护。

## 学习纪律

- 每个概念走一遍「公式推导 → LTspice/Logisim → 实物/仪器」，缺一环不算完成
- 笔记记结论更要记**为什么**：实测与理论不符处是最值钱的笔记
- 某天断了：第二天补 1.5h，不压缩周末实验；连续断 3 天启动砍配规则
- **砍配规则**（时间被压缩时）：保 W4/W8/W12/W15/W17 里程碑；砍 Logisim 设计题、555 制作、Boost 仿真；项目可退回「成品 Buck 模块 + MCU 调压」不画自制板
